Featured Flowers images (homepage strip)
----------------------------------------
Drop your photos into this folder using these exact file names:

  tulip-pink.jpg
  rose-red.jpg
  sunflower.jpg
  lily-stargazer.jpg

Tips
- Portrait photos (4:5 ratio, e.g. 800 x 1000 px) display with no cropping.
- Any other ratio is centered and trimmed slightly to keep every image the same size.
- To add more flowers to the strip, add an entry to `featuredImageFiles`
  and to `featuredSelection` in js/app.js (renderHomeView).
- Until a file exists here, the strip shows the previous catalog photo for that flower.
